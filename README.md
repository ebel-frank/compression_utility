# Compression Utility - gfwrap

A lightweight, efficient file compression utility for Linux systems. This tool provides fast compression and decompression capabilities.

## Features

- **Multiple Compression Formats**: Support for gzip, bzip2, xz, and zstd compression
- **Batch Processing**: Compress or decompress multiple files at once
- **Recursive Directory Compression**: Compress entire directory trees
- **Preserve Permissions**: Maintains file permissions and timestamps
- **Progress Indication**: Visual feedback during compression operations
- **Configurable Compression Levels**: Choose between speed and compression ratio

## Installation

### Prerequisites

- Linux (Ubuntu 18.04+, CentOS 7+, Debian 9+, or similar)
- GCC/Clang compiler or pre-built binaries
